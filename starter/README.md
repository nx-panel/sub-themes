# Starter

The smallest complete NX subscription page, written to be copied. One
`index.html` and one `style.css`, system fonts, light and dark, right to left
for Persian.

It shows the account's status, usage and expiry, the subscription address with
its QR code, buttons that add it to common apps, each configuration with a
copy button, config files for apps that need one, the panel's notices and a
support link. Usage refreshes every 30 seconds without a reload.

Every section is independent: delete what you do not need. The comments in
`index.html` explain the parts that are easy to get wrong.
